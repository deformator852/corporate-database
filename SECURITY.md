# Security policy

Corpus stores confidential company documents, so security reports are welcome.

## Reporting a vulnerability

Email [kostneko30@gmail.com](mailto:kostneko30@gmail.com). Do not open a public
issue, because that exposes every installation until a fix is out.

Include:

* What an attacker can do, and what they need first, such as an account with a
  given role
* The steps to reproduce it
* The Corpus version, shown on the **System status** page

Do not include real documents, chat content or secrets. Test only on your own
installation.

You get an answer within 7 days. This is a project maintained by one person,
with no bug bounty. You are credited in the release notes, unless you prefer
otherwise.

## Supported versions

Fixes go into the latest release only.
